공장의 모든 신호를
하나의 화면으로.

설비 가동 상태부터 원시 센서 신호까지, 현장 데이터를 실시간으로 수집·시각화·제어합니다.
TCC INS의 스마트 팩토리 솔루션은 HMI, 빅데이터, DAQ를 제공합니다.

HMI Big Data DAQ

Solution 01

HMI

공장 가동 현황,
한 화면에서 제어합니다.

설비 상태를 실시간으로 모니터링하고, 에러 발생 위치를 즉시 확인하며, 현장에 가지 않아도 작업 지시를 내릴 수 있습니다.

Core Features

실시간 설비 상태 모니터링

라인별 설비의 가동·정지·에러 상태를 한 화면에서 확인합니다. 이상 발생 시 즉각 알림이 전달되어 빠른 대응이 가능합니다.

가동률 실시간 집계 · 설비별 상태 표시 · 이상 알림

에러 발생 위치 즉시 감지

공정 도면 위에 에러 발생 위치를 시각화합니다. 어느 라인의 어떤 설비에서 무슨 에러가 발생했는지 직관적으로 파악합니다.

에러 코드 분류 · 위치 시각화 · 이력 기록

화면에서 바로 작업 지시

현장에 가지 않아도 HMI 화면에서 작업 지시를 발행하고 완료 여부를 확인합니다. 지시 이력은 자동으로 기록됩니다.

작업 지시 발행 · 완료 확인 · 이력 자동 저장

HMI · 원격 제어

현장에 가지 않아도 됩니다.

공장 내 모든 설비의 상태를 PC·태블릿 어디서든 확인하고 제어합니다.
이상 발생 시 담당자에게 즉시 알림이 전달되고, 화면에서 바로 조치를 취할 수 있습니다.

Solution 02

Big Data

공장 안 모든 데이터가
실시간 차트가 됩니다.

수백 개의 공정 태그를 실시간으로 수집하고 그래프화합니다.
원하는 지표를 자유롭게 조합해 비교·분석하고 이상 패턴을 사전에 감지합니다.

Core Features

전 공정 데이터 실시간 그래프화

공장 내 가동되는 모든 설비의 데이터를 실시간으로 수집하고 즉시 차트로 시각화합니다. 수백 개의 태그를 동시에 추적합니다.

실시간 태그 수집 · 자동 차트 생성 · 다채널 동시 표시

다중 지표 비교·조회

기간, 라인, 설비를 자유롭게 조합해 원하는 데이터를 즉시 조회하고 비교합니다. 과거 데이터와 현재 트렌드를 나란히 확인합니다.

기간별 조회 · 설비 간 비교 · 커스텀 대시보드

이상 패턴 감지 및 추세 분석

데이터 패턴에서 이상 징후를 사전에 감지합니다. 추세 분석을 통해 설비 이상을 예측하고 예방적 유지보수를 지원합니다.

이상 감지 알림 · 추세 예측 · 예방 유지보수 지원

Big Data · 실시간 시각화

수백 개의 태그,
하나의 대시보드로.

설비마다 쌓이는 방대한 데이터를 하나의 통합 대시보드에서 확인합니다.
원하는 지표를 자유롭게 조합하고, 이상 발생 시 즉각 대응하세요.

Solution 03

DAQ

센서 신호를
디지털 데이터로 변환합니다.

온도·압력·전압·전류 등 현장의 아날로그 신호를 신호 조절 장치를 통해 정밀하게 디지털화합니다.
수집된 데이터는 HMI와 빅데이터 시스템으로 즉시 전달됩니다.

DAQ 데이터 흐름

Core Features

다종 센서 입력 지원

온도, 압력, 전압, 전류, 진동 등 다양한 종류의 센서 신호를 단일 시스템에서 동시에 수집합니다. 센서 종류에 관계없이 통합 관리됩니다.

온도 · 압력 · 전압 · 전류 · 진동 · 유량

신호 조절 및 노이즈 필터링

아날로그 신호를 증폭·필터링·격리하여 정밀한 데이터를 확보합니다.
전기적 노이즈와 간섭을 차단해 신뢰할 수 있는 측정값을 제공합니다.

신호 증폭 · 노이즈 차단 · 전기 격리

실시간 변환 · 상위 시스템 연동

아날로그 신호를 고속으로 디지털 변환하여 HMI·빅데이터 시스템에 즉시 전달합니다. 데이터 수집부터 활용까지 끊김 없이 연결됩니다.

고속 A/D 변환 · HMI 연동 · 빅데이터 연동

DAQ · 통합 연결

센서에서 대시보드까지,
끊김 없이 연결됩니다.

DAQ가 수집한 원시 신호는 HMI에서 제어에 활용되고, 빅데이터 시스템에서 분석됩니다. 센서부터 의사결정까지 하나의 데이터 파이프라인으로 통합합니다.
