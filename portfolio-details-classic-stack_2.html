AI CCTV

카메라가 재고를 셉니다

입고·출고를 사람이 직접 세지 않아도 됩니다. AI CCTV가 실시간으로 재고를 인식하고, 지게차에 장착된 카메라가 이동하면서 창고 전체의 재고를 자동으로 파악합니다.

입고·출고 자동 인식 · 지게차 카메라 연동 · 실시간 재고 추적

3D Simulation

공장을 화면 안에 그대로 옮깁니다

창고를 3D로 구현해 재고 배치를 가상으로 시뮬레이션합니다. 코일 공장의 기계를 3D로 그려 측정값을 입력하면, 실제 가동 전에 결과를 미리 확인할 수 있습니다. 사고 전에 대응합니다.

3D 창고 시뮬레이션 · 기계 가상 구현 · 사전 결과 예측 (R&D)

MES · SCADA · Big Data

공정 전체가 실시간으로 연결됩니다

Web HMI·SCADA로 공정을 실시간 모니터링하고, MES·QMS로 생산·품질을 통합 관리합니다. FDC·SPC 기반 빅데이터 분석으로 불량을 사전에 감지하고 설비 이상을 예측합니다.
